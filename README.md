## Results storage

- `Results_Rough` stays in this repository and is **never** sent to the Google Drive.
- `Results_Main` is stored on the shared drive at `G:\Shared drives\TUPIL\Hikaru Kurosawa - MBP PhD Student - 2026\Results Storage\Results_Main`.
